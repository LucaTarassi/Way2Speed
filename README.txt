WAY2SPEED — MINI TUTO
=====================

LIEN PRINCIPAL
--------------
- Ouvrir le site : index.html
- Le site utilise uniquement des fichiers statiques : HTML / CSS / JS / assets

OUVRIR LE SITE EN LOCAL
-----------------------
1. Dézippe le dossier si besoin.
2. Ouvre le fichier "index.html" dans ton navigateur.
3. Si certaines vidéos externes chargent mal en local, passe par un petit serveur local.

SERVEUR LOCAL SIMPLE (OPTIONNEL)
--------------------------------
Si tu as VS Code :
- installe l’extension "Live Server"
- clic droit sur index.html
- "Open with Live Server"

MODIFIER LES CONTENUS RAPIDEMENT
--------------------------------
1. Logo home page
   - Fichier : assets/way2speed-logo-chrome.png

2. Cartes artistes
   - Moonarch : assets/moonarch-cutout.png
   - Manas : assets/manas-cutout.png
   - Les liens Instagram sont dans index.html, section #artists

3. Vidéo de fond de la home
   - Le lien YouTube embed est dans index.html, dans la section .video-bg > iframe

4. Réseaux "Rejoins le Way2Crew !"
   - Les 3 liens sont dans la section #crew de index.html

5. Style général / couleurs / animations
   - Tout le design est principalement dans styles.css
   - Les effets interactifs sont dans script.js

SECTIONS DU SITE
----------------
- WAY2ARTISTES
- WAY2MUSIC
- WAY2MERCH
- WAY2SHOW
- Footer social / Way2Crew

BON À SAVOIR
------------
- Les cartes artistes sont désormais détourées et cliquables.
- Un clic sur Moonarch ou Manas ouvre directement leur Instagram.
- Le footer social comprend : SoundCloud / YouTube / Instagram.
