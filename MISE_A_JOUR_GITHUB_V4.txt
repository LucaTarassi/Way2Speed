METTRE A JOUR SUR GITHUB
------------------------
1. Decompresser le ZIP way2speed-v4-github-update.zip.
2. Sur https://github.com/LucaTarassi/Way2Speed, ouvrir Add file > Upload files.
3. IMPORTANT: le dossier assets doit rester un dossier: deposer ensemble
   index.html, styles.css, ET le dossier assets qui contient les 3 pochettes JPG.
   Si votre navigateur n'accepte pas l'envoi du dossier avec les fichiers,
   ouvrir le dossier assets du depot et y televerser les 3 JPG separement.
4. Ne pas televerser le fichier ZIP tel quel.
5. Cliquer Commit changes sur la branche main.
6. Vercel redeploie automatiquement. Ouvrir ensuite https://way2speed.vercel.app/
7. Si l'ancienne version apparait, appuyer sur Ctrl + F5.

Les anciens assets ne doivent pas etre supprimes.
